# Latex

Latex is a Fabric mod that adds liquid latex, rubber trees, rubber tools and armor, a new enchantment, a bouncing ender pearl, a new biome, and a structure.

# Building

To build the project, open your terminal in the root folder and run the command for your operating system:

## macOS / Linux
```bash
./gradlew build
```

## Windows

### CMD

```cmd
gradlew build
```
### Powershell

```powershell
.\gradlew build
```

The build artifacts will be located in the `build/libs/` directory.


![Latex pool, with rubber trees behind it.](https://cdn.modrinth.com/data/aw5o1dSg/images/e2b73a9d38331453f8e5655857bd67d6f31f09dc.png)

## Getting latex

In the Rainforest, put a cauldron under a rubber log (up to 16 blocks below, air in between). It converts and fills over about a minute. Pick it up with an empty bucket for a Bucket of Latex. Smelt the bucket for 5 Loose Rubber.

![Cauldren with Latex](https://cdn.modrinth.com/data/aw5o1dSg/images/98c7552518875927cc3260931392b2fec2a4f1c2.png)

## Tools

**Rubber Pickaxe**: 1 self-damage and knockback on every swing.

**Rubber Axe**: hidden Wind Burst 3 (no glint, no tooltip).

**Rubber Shovel**: same self-damage as the pickaxe. 

**Rubber Hoe**: tills 3x3x3 around the clicked block per use. 

**Rubber Sword**: reflects half your dealt damage plus matching knockback onto you. 

**Rubber Spear**: Infinite holdable charge, no extra hunger.

![Rubber Tools](https://cdn.modrinth.com/data/aw5o1dSg/images/f853d227d467c34d8ab4b7109f183954131ca865.png)

## Armor (Loose Rubber, standard recipes)

**Boots**: no fall damage; every landing bounces you back to your takeoff spot, once.

**Leggings**: hidden Swift Sneak 5.

**Chestplate**: hidden Bounce 2, launches melee attackers. 

**Helmet**: no special effects.

**Bounce**: Bounce 1 gives attacker knockback, you can get it in Rubber Tower loot. Bounce 2 launches attackers; not obtainable in survival.

## Rubberpearl

Crafteble using an ender pearl loose rubber. Bounces off blocks exactly twice, then teleports like a normal pearl.

![Rubber Tower](https://cdn.modrinth.com/data/aw5o1dSg/images/a8031fd20f81481ad993536c56e5d4f22c34a7f1.png)

## The Rubber Tower

An high tower, found in rainforests. Contains Latex Pools and loot, including the new Bounce 1 book.

## Installation

Drop the downloaded JAR into your mods folder. No new world needed but keep in mind that the biome and tower appear only in unexplored chunks.

![Full Rubber armor](https://cdn.modrinth.com/data/aw5o1dSg/images/d44613812addec36e1e14169b498d84d3744d353.png)

Requires Minecraft 26.3, Fabric Loader 0.19.5+, Fabric API 0.161.0+26.3, Java 25. Required to be on the clients and the server.
